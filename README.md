# Sugar Generation

An open-source archive for readers to explore the world of my novel
*Sugar Generation*.

## About

This repository contains the data, code, and visualizations used to
construct and explore the fictional world of *Sugar Generation*.

The maps and scenario data are based on real-world datasets and
fictional assumptions developed for the novel.

## Repository Structure

- `code/` — Python scripts used to generate maps and visualizations
- `data/` — Data used in the analysis
- `output/` — Maps and other generated visualizations

## Data Sources

- FAOSTAT
- Natural Earth

## Note

The future scenarios presented here are fictional and were created
as part of the worldbuilding for *Sugar Generation*. They are not
intended as forecasts or scientific predictions.
